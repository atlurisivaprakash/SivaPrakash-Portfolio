# Siva Prakash — HTML & CSS Portfolio

## Files
- `index.html` — semantic HTML structure and page content
- `style.css` — colours, layout, cards, hover states and responsive breakpoints
- `images/` — optional images (not required for this design)
- `screenshots/` — save desktop and mobile screenshots here before submission

## Run locally
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in Chrome, or use the Live Server extension if already installed.
4. Edit the text in `index.html`; edit the colours in the `:root` section at the top of `style.css`.

## Must edit before publishing
1. Replace `your.email@example.com` with an email address you are comfortable publishing.
2. Replace the LinkedIn and GitHub links with your actual public profiles.
3. Verify the skills and project descriptions are accurate. Keep only completed or honestly labelled in-progress work.
4. Check every navigation link and test the page at desktop and phone widths.
5. Capture desktop and mobile screenshots into `screenshots/`.

## Constraints
This starter uses HTML5 and CSS3 only for its core functionality, as required by the internship guide. Google Fonts is loaded from an external stylesheet; the page still has fallback fonts if that request fails. No JavaScript, React, Bootstrap, backend, or database is used.
